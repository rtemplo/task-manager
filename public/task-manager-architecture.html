Custom Hooks

Hook Consumed By Purpose
useDragAndDrop TaskColumn, TaskCard Manages drag events for cross-column drops and vertical reordering; calls taskApi.updateStatus() and reads/writes custom sequences via TaskManagerContext
useDebounce ControlBar Debounces the search input value with a 300 ms delay
useEscapeKey TaskModal, FilterModal, SortModal, TaskCard, DeleteConfirmPopover Registers a keydown listener that fires a callback when Escape is pressed; used to close modals and popovers
useLocalStorage TaskManagerContext Persists custom task sequences to localStorage so column ordering survives page reloads
useTaskFiltering TaskManagerContext Applies the active filter criteria (priorities, assignees, bookmarks, due date, search query) to the full task list
useTaskSorting TaskManagerContext Groups tasks by status and applies per-column sort configurations (field + direction + custom sequence)
useBookmarkSanitizer TaskManagerContext Detects and removes stale bookmark IDs after tasks are deleted; calls appStateApi.removeBookmark() and appStateApi.get()
